How a diffusion model generates an image

In this short section, we considered diffusion models of various levels of sophistication.

All the pictures are real outputs from the lectures: google/ddpm-cat-256, a small class-conditional MNIST model trained for lecture 16, and Stable Diffusion v1.5. The forward process is computed exactly.

Refine the whole image

  • A VAE decodes an image in one shot, and blurs it. A language model builds its output one token at a time.
  • A diffusion model starts from pure noise, and refines the whole image a little at each step, usually for hundreds of steps.
  • Every step calls the same network. Its inputs are the subject of this page.
  • A real generation by google/ddpm-cat-256, from $t = 999$ to $t = 0$.

Destroying an image is easy

  • The forward process mixes an image $x_0$ with Gaussian noise $\epsilon$, in $T = 1000$ small steps. It needs no learning.
  • Small steps of Gaussian noise add up to one big one, so we can jump straight to any step: $x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1-\bar\alpha_t}\,\epsilon$.
  • The list $\beta_1, \ldots, \beta_T$ of noise added at each step is the noise schedule, and fixes how fast $\sqrt{\bar\alpha_t}$, the share of image left, falls to 0.

One jump blurs, so take small steps

  • From a noisy $x_t$, the best guess at $x_0$ (under mean squared error) is the average of every image that could have produced it: sharp when $t$ is small, little more than an average colour at $t = 999$. That's the VAE's blur again.
  • So we don't jump. We guess, move a little way towards the guess, and guess again from a slightly cleaner input. Early steps settle what the picture is; later ones, the detail.
  • Top: the image $x_t$. Bottom: the model's guess $\hat x_0$ at that step.

Train by predicting the noise

  • Training: pick an image $x_0$, a step $t$ and noise $\epsilon$; make $x_t$ in one jump; ask the network for $\hat\epsilon$; minimise $\lVert \epsilon - \hat\epsilon_\theta \rVert^2$. No labels are needed.
  • Predicting the clean image also works. Given $x_t$ and $t$, either gives the other, but the noise has the same size at every step, so it trains more stably.
  • The network is a UNet: an image in, an image-sized prediction out, with skip connections that carry fine detail across.
  • It is also told $t$, since the same noisy pixel means different things at $t = 50$ and $t = 950$.

Input: a label $y$

  • To say which image, give the network a condition $y$, in training and at every sampling step. It then samples from $p(x \mid y)$, not $p(x)$.
  • A class label is a row of a learned lookup table, like a token embedding, added to the time embedding. Data, noise, schedule and loss are unchanged. In lab 16's model, the table is 1,280 of 15,892,033 parameters.
  • The label decides which digit; the noise decides how it's drawn. But only trained classes are possible, similar classes get confused, and the label can be under-used.

Input upgraded: a latent $z_t$

  • At 512 × 512, every step would run the UNet over 786,432 numbers.
  • Stable Diffusion's VAE, trained once and then frozen, compresses an image to a 4 × 64 × 64 latent. It is still image-shaped, so the same UNet recipe works on it.
  • Latent diffusion runs every step on the latent, and decodes to pixels once, at the end.
  • A photo, its four latent channels, and its decoding.

Input upgraded: a prompt

  • A prompt can be any sentence, so there is no lookup table. Instead, CLIP's frozen text tower gives one vector per token: 77 × 768.
  • The UNet reads them by cross-attention: queries from image positions, keys and values from tokens. Each part of the image looks up the words that concern it.
  • “a lighthouse on a rocky cliff above the sea at sunset, oil painting”: where the image attends to “lighthouse”.

Call it twice: guidance

  • Training drops the prompt 10% of the time, so one network can predict with and without it.
  • Classifier-free guidance runs both at each step, and exaggerates the difference: $\hat\epsilon = \hat\epsilon_{\text{uncond}} + s\,(\hat\epsilon_{\text{cond}} - \hat\epsilon_{\text{uncond}})$.
  • Higher $s$ follows the prompt more closely, with less variety. It can only exaggerate what the text encoder captured: with noise A, red and yellow swap places.
  • “a red bicycle leaning against a yellow wall”, Stable Diffusion v1.5, 30 steps.
